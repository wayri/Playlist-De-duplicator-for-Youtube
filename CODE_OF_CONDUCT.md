# Code of Conduct

Be respectful, technical, and constructive.

This project welcomes bug reports, documentation improvements, testing, translations, and code contributions from anyone willing to collaborate in good faith.

Harassment, personal attacks, discriminatory abuse, threats, deliberate disruption, credential sharing, or publishing another person's private information are not acceptable.

Technical disagreement is fine. Focus criticism on code, behavior, evidence, safety, and maintainability rather than the person making the contribution.

Maintainers may edit, hide, lock, or remove contributions that materially violate these expectations.
