# Playlist Deduper for YouTube™ v1.3.0

The first public GitHub release of the redesigned, privacy-first playlist deduplication extension.

## Install in about a minute

1. Download **`playlist-deduper-for-youtube-v1.3.0-offline.zip`** below.
2. Extract the ZIP to a permanent folder.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted `Playlist-Deduper-for-YouTube` folder (the one containing `manifest.json`).
7. Pin the extension, open an editable YouTube playlist, and click **Scan full playlist**.

Full instructions, updates, uninstall steps, Chromium-browser notes, and troubleshooting are in [`docs/INSTALLATION.md`](../../docs/INSTALLATION.md).

## Highlights

- Exact duplicate matching by YouTube video ID.
- Full lazy-loaded playlist scanning.
- Review-first duplicate cards with exact playlist positions.
- Selective cleanup by duplicate group.
- Keep-first or keep-last behavior.
- Search and sorting for large duplicate sets.
- CSV and readable report export.
- Explicit confirmation before playlist modification.
- Rate-limited, cancellable cleanup with post-action verification.
- Conservative fail-closed behavior when YouTube's remove action cannot be identified safely.
- Private/deleted/unidentified entry diagnostics.
- No API key, OAuth login, analytics, backend, or playlist-data upload.
- Minimal permissions: `activeTab`, `scripting`, `storage`.

## Download choice

- **`*-offline.zip`** — recommended for normal GitHub installation.
- **`*-store.zip`** — exact runtime-oriented archive intended for Chrome Web Store submission.
- **`*-source.zip`** — full source/documentation snapshot.

## Important compatibility note

YouTube is a frequently changing single-page application. A future YouTube DOM/menu change can break scanning or removal. Destructive actions are designed to fail closed rather than guess.

If you encounter a compatibility regression, first stop cleanup, preserve the failing playlist state if possible, and open a bug report with your Chrome version, extension version, YouTube UI language, and reproduction steps.
