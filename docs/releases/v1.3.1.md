# Playlist Deduper for YouTube™ v1.3.1

This release binds cleanup to the reviewed playlist and scan snapshot, locks concurrent operations, and refuses stale context, changed survivors, or ambiguous removal menus. It recognizes only exact English removal commands. Scans can be partial when loading is limited or continuation remains. CSV export neutralizes spreadsheet formulas.

Live Chrome regression testing: **pending**. Record actual results before publication; see `TEST_PLAN.md` and release evidence.

## Install

Download `playlist-deduper-for-youtube-v1.3.1-offline.zip`, extract it to a permanent location, open `chrome://extensions`, enable Developer mode, and choose **Load unpacked**. Select the extracted `Playlist-Deduper-for-YouTube` folder containing `manifest.json`.

The release also includes Store and source ZIPs. Chrome Web Store submission has not yet occurred.
