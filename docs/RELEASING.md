# Release Process

1. Update the manifest/package version together, changelog and release notes.
2. Run `npm test`, then `npm run package`. The Bash and PowerShell wrappers invoke the same dependency-free Node packager. It normalizes text to LF and creates deterministic Store, offline and source ZIPs plus `dist/SHA256SUMS.txt`. The Store ZIP includes runtime files and required license/notice texts; the offline ZIP adds `INSTALL.txt` and a named extension folder. Source packaging uses an explicit set of repository directories and root file types, excluding Git metadata, dependencies and `dist`.
3. Run `python scripts/check-archives.py` (Python 3.9+) to independently verify ZIP CRCs, contents, versions, source bytes and checksums. CI runs validation and packaging on Linux and Windows.
4. Push the candidate branch and inspect its PR checks. For a draft, manually dispatch `release.yml` with the candidate branch as `--ref` and its exact full commit SHA as `expected_sha`. The workflow repeats validation, behavior tests, packaging and archive checks before creating a **draft** release. It refuses to overwrite an existing release.
5. Complete [the live test plan](../TEST_PLAN.md) on that exact source in current Chrome with a disposable editable playlist and English YouTube UI. Record actual environment, counts, survivor positions and results. Fixture tests and screenshots do not prove current YouTube compatibility.
6. After live checks pass, merge the reviewed source, confirm the release target still matches the tested code, and publish the draft with `gh release edit vX.Y.Z --draft=false`. If runtime files change, rebuild, rerun tests and live regression, and replace only unpublished draft assets. Never overwrite a published release.
7. Complete the Store draft using [PUBLISHING.md](../PUBLISHING.md), check that its ZIP checksum equals the release Store ZIP, then submit for review. Record the actual status. Update README with an install URL only when the Dashboard provides one; label pending review accurately and claim availability only after publication is confirmed.
