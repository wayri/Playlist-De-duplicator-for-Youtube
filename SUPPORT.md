# Support

## Before filing an issue

1. Confirm you are on a dedicated YouTube playlist page (`/playlist?list=...`).
2. Reload the YouTube page.
3. Reload the extension from `chrome://extensions` if using an unpacked build.
4. Run **Scan full playlist** again.
5. Check `docs/TROUBLESHOOTING.md`.

## Good bug reports include

- Chrome/Chromium browser name and version.
- Extension version.
- YouTube interface language.
- Whether the playlist is owned/editable by you.
- Approximate playlist size.
- Whether scan, review, or cleanup failed.
- Exact error/status text shown by the extension.
- Console errors from the extension popup or YouTube tab, with personal data removed.
- A screenshot if it does not expose private playlist/account information.

Do not post private playlist URLs, account identifiers, cookies, tokens, or other credentials.
