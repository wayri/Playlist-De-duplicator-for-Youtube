UPLOAD THIS PROJECT TO GITHUB

Repository target:
https://github.com/wayri/Playlist-De-duplicator-for-Youtube

Windows:
1. Extract this ZIP.
2. Open the extracted folder in PowerShell.
3. Run: .\PUSH_TO_GITHUB.ps1
4. If GitHub asks you to sign in, complete the Git credential prompt.

macOS/Linux:
1. Extract this ZIP.
2. Open a terminal in the extracted folder.
3. Run: ./push-to-github.sh

The first push uses the commit subject "Release v1.3.0...". The included GitHub Actions release workflow will validate/package the extension and publish v1.3.0 with offline, Store, and source ZIP assets.
