# Store Asset Checklist

Create the final assets **after live-testing v1.2.0** so every screenshot represents the shipping UI.

## Required/strongly recommended assets

- `icon128.png` — already supplied in `icons/`.
- At least 1 screenshot at **1280×800** (prepare 3–5).
- Small promo tile at **440×280**.
- Optional marquee tile at **1400×560**.

## Recommended screenshot set

1. Full playlist scanned with several duplicate groups visible.
2. Duplicate positions + selective checkboxes + keep-first/keep-last controls.
3. Search/filter or sort in action.
4. CSV/report actions and skipped-entry diagnostics.
5. Confirmation state immediately before safe removal.

Use actual Chrome/YouTube/extension UI. Avoid invented ratings, “Featured” badges, download counts, or claims not yet earned.

## Branding

Use the extension's purple duplicate-list mark. Do not use or modify the YouTube logo. If YouTube appears in explanatory text, keep the relationship phrased as compatibility and retain the non-affiliation/trademark notice in the store description.
